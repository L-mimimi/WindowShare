========================================
  窗享 WindowShare 便携版
  只读屏幕/窗口共享 · 无远程控制功能
========================================

目录说明
--------
  WindowShare.Host.exe          共享端：捕获本机屏幕/窗口并发送
  WindowShare.Viewer.exe        观看端：接收并显示
  data\                         便携数据目录（日志 / 白名单 / 录制文件）
  signaling\                    信令服务器（跨网段时才需要）
  启动-共享端.bat               双击运行共享端（带使用提示）
  启动-观看端.bat               双击运行观看端（带使用提示）
  启动-信令服务器.bat           双击启动信令服务器
  portable.marker               便携模式标记（删除它即恢复安装模式）

快速上手
--------
局域网（最简单）
  1. 在【被共享的电脑】上双击 启动-共享端.bat
  2. 选择屏幕或窗口 → 选画质 → 点「开始共享」
  3. 记下界面上的房间号与密码
  4. 在【观看的电脑】上双击 启动-观看端.bat
  5. 选「直连 IP」，填 Host 的 IP + 密码 → 连接
  6. Host 会弹出设备审批框，点「允许并记住」

跨网段（需要信令服务器）
  1. 在任一有公网/内网可达的机器上双击 启动-信令服务器.bat
  2. Host 端勾选「信令服务器（房间号模式）」，地址填 http://服务器IP:5000
  3. Viewer 端选「房间号」，填房间号 + 密码 + 同样的信令地址
  4. 程序会先尝试局域网直连，失败自动回退 WebRTC（P2P，打洞失败走 TURN 中继）

获取本机 IP
-----------
  ipconfig

防火墙放行（管理员 PowerShell / CMD）
------------------------------------
  # 共享端（观看方需要连进来）
  netsh advfirewall firewall add rule name="WindowShare Host" dir=in action=allow protocol=TCP localport=48750

  # 信令服务器
  netsh advfirewall firewall add rule name="WindowShare Signaling" dir=in action=allow protocol=TCP localport=5000

安全说明
--------
  · 每次共享生成新的临时密码，共享结束即失效
  · 新设备首次连接必须由你亲自点「允许」，可选记住
  · 局域网媒体流可选 AES-256-GCM 加密；WebRTC 强制 DTLS-SRTP
  · 共享期间屏幕顶部常驻红色提示条，随时可点「停止」
  · 只共享指定窗口时，窗口之外的内容不会被发送
  · 本软件为只读共享，不含任何键盘鼠标控制功能

数据与便携性
------------
  · 所有数据在 data\ 目录下，不写入系统 %APPDATA%
  · 整个文件夹可直接拷到 U 盘，换电脑即插即用，配置和白名单一起带走
  · 若所在位置不可写（如写保护的 U 盘），会提示并自动回退到 %APPDATA%\WindowShare
  · 想指定数据位置，可设环境变量：set WINDOWSHARE_DATA_DIR=D:\MyData

系统要求
--------
  Windows 10 1903（10.0.18362）或更高，推荐 Windows 11
  已内置 .NET 8 运行时，无需额外安装
